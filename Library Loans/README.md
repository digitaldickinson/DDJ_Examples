# Library Data

## Source 
The data set here came via 
- a FOI request at  https://www.whatdotheyknow.com/request/library_usage_data_20242025_20242130#incoming-3145071  
- Manchester City Council's open data portal - https://www.manchester.gov.uk/downloads/500426/current_libraries_annual_performance_data_-_calendar_year_download

## Content

The folder contains three files:
- [FOI 17044 Library usage data 2024-2025.xlsx](https://github.com/digitaldickinson/DDJ_Examples/blob/main/Library%20Loans/FOI%2017044%20Library%20usage%20data%202024-2025.xlsx "FOI 17044 Library usage data 2024-2025.xlsx") - The data provided in the FOI response
- [Libraries_Key_Performance_Information___Calendar_Year_2024.xlsx](https://github.com/digitaldickinson/DDJ_Examples/blob/main/Library%20Loans/Libraries_Key_Performance_Information___Calendar_Year_2024.xlsx "Libraries_Key_Performance_Information___Calendar_Year_2024.xlsx") - KPI's for Manchester Libraries for 2024. This has been lightly cleaned to remove the table formatting. Previous years are available via the open data portal - https://www.manchester.gov.uk/downloads/500426/current_libraries_annual_performance_data_-_calendar_year_download
- [manchester_libraries_2020_2024_cleaned.csv](https://github.com/digitaldickinson/DDJ_Examples/blob/main/Library%20Loans/manchester_libraries_2020_2024_cleaned.csv "manchester_libraries_2020_2024_cleaned.csv") - A combined and cleaned version of the annual performance data. Use with caution - the data are inconsistent across years, so not all data is available.
- [_Libraries_Key_Information___Calendar_Year_2024.xlsx](https://github.com/digitaldickinson/DDJ_Examples/blob/main/Library%20Loans/_Libraries_Key_Information___Calendar_Year_2024.xlsx "_Libraries_Key_Information___Calendar_Year_2024.xlsx") - general details and lat/long  co-ordinates for Manchester Libraries
