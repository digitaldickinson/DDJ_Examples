# Fly tipping data

## Source 
The data sets here are from https://www.gov.uk/government/statistics/fly-tipping-statistics-for-england/fly-tipping-statistics-for-england-2023-to-2024. 

## Content

There folder contains three files:

- [Flytipping_incidents_and_actions_taken__reported_by_LAs_in_England__2012-13_to_2023-24.ods](https://github.com/digitaldickinson/DDJ_Examples/blob/main/Flytipping/Flytipping_incidents_and_actions_taken__reported_by_LAs_in_England__2012-13_to_2023-24.ods "Flytipping_incidents_and_actions_taken__reported_by_LAs_in_England__2012-13_to_2023-24.ods") - The orginal data file.
- [Flytipping_incidents_and_actions_taken__reported_by_LAs_in_England__2012-13_to_2023-24_CLEAN.xlsx](https://github.com/digitaldickinson/DDJ_Examples/blob/main/Flytipping/Flytipping_incidents_and_actions_taken__reported_by_LAs_in_England__2012-13_to_2023-24_CLEAN.xlsx "Flytipping_incidents_and_actions_taken__reported_by_LAs_in_England__2012-13_to_2023-24_CLEAN.xlsx") - The cleaned version
- [Review of Waste Recycling and Fly-Tipping - With a focus on approach taken in hotspots.pdf](https://github.com/digitaldickinson/DDJ_Examples/blob/main/Flytipping/Review%20of%20Waste%20Recycling%20and%20Fly-Tipping%20-%20With%20a%20focus%20on%20approach%20taken%20in%20hotspots.pdf "Review of Waste Recycling and Fly-Tipping - With a focus on approach taken in hotspots.pdf") - Document from Manchester City council with some data and context for flytipping in Manchester.
