# Education Appeals

## Source 
The data sets here are created from education data provided by the UK Government's Education Statistics Explorer - https://explore-education-statistics.service.gov.uk/

## Content

The folder contains three files:

- [AdmissionsAppeals_LA.csv](https://github.com/digitaldickinson/DDJ_Examples/blob/main/Education_Appeals/AdmissionsAppeals_LA.csv "AdmissionsAppeals_LA.csv") The original data from the explorer. If you intend to do any further analysis on this data, you're advised to check the source for any updates. 
- [AdmissionsAppeals_LA_CLEAN.xlsx](https://github.com/digitaldickinson/DDJ_Examples/blob/main/Education_Appeals/AdmissionsAppeals_LA_CLEAN.xlsx "AdmissionsAppeals_LA_CLEAN.xlsx") - A cleaner version of the data in Excel format. 
- [Admissions Appeals by LA - cleaning recipe.docx](https://github.com/digitaldickinson/DDJ_Examples/blob/main/Education_Appeals/Admissions%20Appeals%20by%20LA%20-%20cleaning%20recipe.docx "Admissions Appeals by LA - cleaning recipe.docx") - A short Word Document with some step-by-step instructions and context for the changes made.
