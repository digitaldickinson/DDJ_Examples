# Library Data

## Source 
The data sets here came via the following sources 
- UK Sport https://www.uksport.gov.uk/resources/transparency-and-open-data
- ONS reporting on Sports engagement  -https://www.ons.gov.uk/peoplepopulationandcommunity/wellbeing/datasets/sportsengagementbylocalauthoritydistrictladinengland

## Content

The folder contains the following files:
- [Grant_information.csv](https://github.com/digitaldickinson/DDJ_Examples/blob/main/Sport%20data/Grant_information.csv "Grant_information.csv") - Data from UK Sports on Grant Payments made in the last Five Years
- [accesstoamenitiessportsengagement.xlsx](https://github.com/digitaldickinson/DDJ_Examples/blob/main/Sport%20data/accesstoamenitiessportsengagement.xlsx "accesstoamenitiessportsengagement.xlsx")- Sports engagement by Local Authority District (LAD) in England
