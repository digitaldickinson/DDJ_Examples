## A collection of data for Mobile and Digital Students to use
Includes
  - **FHRS415en-GB.csv** - Food Hygene ratings for Manchester from the FHRS - https://data.food.gov.uk/catalog/datasets/38dd8d6a-5ab1-4f50-b753-ab33288e3200
- **/Driving Tests/** - A folder of data and resources based on driving test data from https://www.gov.uk/government/statistical-data-sets/driving-test-and-theory-test-data-cars
- **/Education_Appeals/** - A folder of data and resources based on education data from [ https://www.gov.uk/government/statistical-data-sets/driving-test-and-theory-test-data-cars](https://explore-education-statistics.service.gov.uk/)
