# AirBnB data for Manchester

## Source 
The data sets here are created by https://insideairbnb.com/. It was created by scraping AirBnB listing.s

## Content

There folder contains four files:
- [listings.csv](https://github.com/digitaldickinson/DDJ_Examples/blob/main/AirBnB%20data/listings.csv "listings.csv") - The original listings data from Insideairbnb. If you intend to do any further analysis on this data, you're advised to check the source for any updates.
- [listings_clean.xlsx](https://github.com/digitaldickinson/DDJ_Examples/blob/main/AirBnB%20data/listings_clean.xlsx "listings_clean.xlsx") - A cleaned up Excel version of the data
- [AirBNB Manchester data.docx](https://github.com/digitaldickinson/DDJ_Examples/blob/main/AirBnB%20data/AirBNB%20Manchester%20data.docx "AirBNB Manchester data.docx") - A word document explaining how some of the data was cleaned and why.
- [guestnightsnightsstaysbymonthnov25.xlsx](https://github.com/digitaldickinson/DDJ_Examples/blob/main/AirBnB%20data/guestnightsnightsstaysbymonthnov25.xlsx "guestnightsnightsstaysbymonthnov25.xlsx") -  Data from ONS bulletin -  Short-term lets through online collaborative economy platforms# Short-term lets through online collaborative economy platforms. Available  at https://www.ons.gov.uk/peoplepopulationandcommunity/housing/bulletins/shorttermletsthroughonlinecollaborativeeconomyplatformsuk/july2024tojune2025
