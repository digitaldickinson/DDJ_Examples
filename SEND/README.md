# SEND Data

## Source 
The data sets here are from sources that relate to SEN/SEND data. This includes data from Tribunal outcomes and data from the Department for Education's data explorer
- https://www.gov.uk/government/statistics/tribunals-statistics-quarterly-july-to-september-2025/
- https://explore-education-statistics.service.gov.uk/data-tables

## Content

The folder contains three files:

- [Tribunals_SEND_2024-25_Tables.ods](https://github.com/digitaldickinson/DDJ_Examples/blob/main/SEND/Tribunals_SEND_2024-25_Tables.ods "Tribunals_SEND_2024-25_Tables.ods") - Tribunal data.
- [sen_ncyear_NW_CLEAN.xlsx](https://github.com/digitaldickinson/DDJ_Examples/blob/main/SEND/sen_ncyear_NW_CLEAN.xlsx "sen_ncyear_NW_CLEAN.xlsx") SEN data (England and the NW). This is a subset of the original dataset. 
- [data-guidance.txt](https://github.com/digitaldickinson/DDJ_Examples/blob/main/SEND/data-guidance.txt "data-guidance.txt") - The file with guidance and notes for the original SEN_NCYEAR dataset.
