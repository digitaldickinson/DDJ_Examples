# Driving test data

## Source 
The data sets here are derived from: 
- DRT121C - Car driving tests conducted, passed and pass rates by month, financial quarter and financial year, gender, Great Britain, from April 2007 to September 2025

It's published by the government as part of a collection of data on Driving test and theory tests. https://www.gov.uk/government/statistical-data-sets/driving-test-and-theory-test-data-cars 

## Content

The folder contains three files

- [drt121c-car-driving-tests-year-gender-age-great-britain.ods](https://github.com/digitaldickinson/DDJ_Examples/blob/main/Driving%20Tests/drt121c-car-driving-tests-year-gender-age-great-britain.ods "drt121c-car-driving-tests-year-gender-age-great-britain.ods") The original file.  This is included for reference. You are advised to check the source website for updates. 
- [drt121c_clean.xlsx](https://github.com/digitaldickinson/DDJ_Examples/blob/main/Driving%20Tests/drt121c_clean.xlsx "drt121c_clean.xlsx") An Excel file with a version of the data cleaned to make it easier to explore.
- [DRT121C - cleaning recipe.docx][drt121c_clean.xlsx](https://github.com/digitaldickinson/DDJ_Examples/blob/main/Driving%20Tests/drt121c_clean.xlsx "drt121c_clean.xlsx")(https://github.com/digitaldickinson/DDJ_Examples/blob/main/Driving%20Tests/DRT121C%20-%20cleaning%20recipe.docx "DRT121C - cleaning recipe.docx") - A Word doc outlining what we did to clean the data. Please have a read through this. It includes some instructions and explanations for what we did
