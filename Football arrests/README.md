# Library Data

## Source 
The data sets here came via two sources 
- the UK Government's  Football-related arrests, banning orders: 2024/25 domestic season data - https://www.gov.uk/government/statistics/football-related-arrests-banning-orders-202425-domestic-season 
- Kick it data on reports of discrimination the organisation has received during the season.  https://www.kickitout.org/reporting-statistics

## Content

The folder contains four files:

- [football-incident-statistics-england-and-wales-detailed-datasets.xlsx](https://github.com/digitaldickinson/DDJ_Examples/blob/main/Football%20arrests/football-incident-statistics-england-and-wales-detailed-datasets.xlsx "football-incident-statistics-england-and-wales-detailed-datasets.xlsx") - Data for incidents reported at games for seasons 2017/18 to 2024/25 
- [football-related-arrest-statistics-england-and-wales-detailed-datasets.xlsx](https://github.com/digitaldickinson/DDJ_Examples/blob/main/Football%20arrests/football-related-arrest-statistics-england-and-wales-detailed-datasets.xlsx "football-related-arrest-statistics-england-and-wales-detailed-datasets.xlsx") - Data for arrests at games for seasons 2019/20 to 2023/24
- [Reporting - End-of-Season Stats 24-25.pdf](https://github.com/digitaldickinson/DDJ_Examples/blob/main/Football%20arrests/Reporting%20-%20End-of-Season%20Stats%2024-25.pdf "Reporting - End-of-Season Stats 24-25.pdf") - KickitOut report on reports of discrimination. This contains the data on incidents from 2019 - 2025
- [KICKITOUT_SCRAPE.xlsx](https://github.com/digitaldickinson/DDJ_Examples/blob/main/Football%20arrests/KICKITOUT_SCRAPE.xlsx "KICKITOUT_SCRAPE.xlsx") A spreadsheet version of the data from page 7 of the report.  Please double-check the numbers.
