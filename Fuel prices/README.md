# Fuel Data

## Source 
The data now requires garages to report their forecourt fuel prices. You can get a CSV file of the latest prices via the Government website -( https://www.developer.fuel-finder.service.gov.uk/ "https://www.developer.fuel-finder.service.gov.uk/")
